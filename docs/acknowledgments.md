# Acknowledgments

RapidRAW was created by [Timon Käch](https://github.com/CyberTimon). This fork builds on his application and its contributors, adding the optional native MCP integration. The README desktop screenshot and the upstream showcase linked from the desktop guide come from the original project.

The following projects and communities contributed tools, research or inspiration:

- [Google AI Studio](https://aistudio.google.com): assistance with upstream algorithm research and implementation.
- [rawler](https://github.com/dnglab/dnglab/tree/main/rawler): RAW file decoding.
- [Lensfun](https://lensfun.github.io/): the lens correction database.
- [LaMa](https://github.com/advimman/lama): local image inpainting.
- [Segment Anything](https://github.com/facebookresearch/segment-anything): subject selection models.
- [U-2-Net](https://github.com/xuebinqin/U-2-Net): foreground and sky selection architecture.
- [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2): monocular depth estimation.
- [nind-denoise](https://github.com/trougnouf/nind-denoise): AI noise reduction models.
- [NegPy](https://github.com/marcinz606/NegPy): inspiration for film-negative conversion.
- [pixls.us](https://discuss.pixls.us/): photography and image-processing knowledge, discussion and feedback.
- [darktable](https://github.com/darktable-org/darktable): reference implementations that informed parts of the editor.
- [libgphoto2](http://gphoto.org/): camera communication for tethering and remote capture.
- [Spektrafilm](https://github.com/andreavolpato/spektrafilm): Andrea Volpato's film-emulation LUTs.

Thanks to the contributors and photographers who test the application, report issues and share their experience.

Support the original author through [upstream RapidRAW](https://github.com/CyberTimon/RapidRAW#support-the-project) or [Ko-fi](https://ko-fi.com/cybertimon). The application and this fork use the [AGPL-3.0 license](../LICENSE).
