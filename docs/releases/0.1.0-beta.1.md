# RapidRAW + MCP 0.1.0 Beta 1

Give your AI agent a native RAW editor with reversible edits and rendered photo review. This first fork beta brings together the desktop editor, 65 MCP tools, local mask and detail enhancement, and configurable AI Connector workflows.

Release tag: `fork-v0.1.0-beta.1`. This is the whole fork's version, independent of upstream RapidRAW. The native bridge reports `1.2.0`; the Node MCP server package reports `0.1.0`.

## Highlights

- Develop RAW photographs, refine masks, compare alternatives, and export JPEG or high-precision 16-bit TIFF through the native engine.
- Keep MCP work recoverable with isolated working copies, saved recipes, undo/redo, named versions and portable sessions.
- Use optional local models for mask refinement, scene and portrait-part selection, experimental deblur and conservative 2× enlargement.
- Choose compatible AI Connector workflows, generation resolution and seed from the desktop panel or MCP. Generative editing requires a separately configured provider.
- Includes frontend type/lint fixes and corrections to preset strength, RAW rendering, export profiles and processing geometry. See the [fork changelog](https://github.com/sheldonxxxx/RapidRAW/blob/fork-v0.1.0-beta.1/CHANGELOG.md).

## Installation

The fork installs as **RapidRAW MCP** and uses its own application identifier for preferences, library state and downloaded models. Existing upstream settings and models are not automatically migrated. Photo sidecars remain beside their images and use the same `.rrdata` format.

Download an asset matching your operating system and architecture from this release. Standard packages include the native MCP bridge; assets marked `tethering` also enable camera tethering. Apple Silicon requires macOS 14+, and Intel Mac requires macOS 13+. The packages are not developer-signed or notarized.

Tethering variants require system **libgphoto2** to be installed before launch. On macOS, use `brew install libgphoto2`; on Ubuntu, use `sudo apt-get install libgphoto2-dev`. The beta DEB installer does not install this optional dependency automatically. See the [camera tethering setup](https://github.com/sheldonxxxx/RapidRAW/blob/fork-v0.1.0-beta.1/docs/desktop-guide.md#camera-tethering) for supported platforms and camera requirements. Standard packages omit this dependency.

**The desktop package alone does not connect an agent.** Install Node.js 22.12+, build the Node host from the matching tag and configure your MCP client using the [beta package setup](https://github.com/sheldonxxxx/RapidRAW/blob/fork-v0.1.0-beta.1/mcp/README.md#connect-a-beta-package). Your client supplies the language model. Model weights and optional companions are installed separately.

## Beta limits

Native MCP editing has been exercised on macOS with Metal and on a Debian 13/NVIDIA server over SSH with Xvfb. Those source-build results do not establish Windows MCP support or fresh-machine acceptance of every packaged download. Review each release's build results separately from photographic quality.

Fine hair and feather masks, panorama framing, genuine HDR/focus brackets and film-negative quality retain acceptance gaps. Deblur and enlargement are experimental. Test on working copies and inspect rendered results before relying on an edit. See the [capability matrix](https://github.com/sheldonxxxx/RapidRAW/blob/fork-v0.1.0-beta.1/mcp/CAPABILITY-MATRIX.md) for detailed limits.

Report reproducible fork issues through [GitHub Issues](https://github.com/sheldonxxxx/RapidRAW/issues), including your OS, architecture, app version and relevant error text. Remove private image paths and credentials from logs before sharing.
