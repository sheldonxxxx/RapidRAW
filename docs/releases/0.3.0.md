# RapidRAW + MCP 0.3.0

Give your AI agent a native RAW editor with reversible edits and rendered photo review. This release adds a more practical generative editing workflow while keeping the original photograph, masks and edit history recoverable.

Release tag: `fork-v0.3.0`. The whole-fork version is independent of upstream RapidRAW. The native bridge and Node MCP host retain their own component versions.

## Highlights

- Use the desktop Inpaint studio to generate one or more variations from a fixed source and selection, apply or disable a candidate with a click, and keep candidate history with the edit across restarts.
- Attach up to four reference images to supported Qwen Image 2.1 and Klein workflows. The source photograph remains the image being edited, while references are passed as auxiliary conditioning and recorded in the generation receipt.
- Use Qwen Remove for brush-selected cleanup without typing a prompt, with source-aware colour matching and optional texture borrowing for suitable uniform surfaces.
- Expand and feather removal coverage, protect selected areas, preview the effective mask without generating pixels, and save the settings with the native patch for reproducible regeneration.
- Keep live editing responsive with bounded slider previews, native pan/zoom transforms, background mask-overlay generation and stale-response protection.
- Continue using photographer-facing Shape Light, Surface Colour and Depth Selection tools alongside the established local and MCP editing workflows.

## Installation and limits

Install a package matching your operating system and architecture from the GitHub release once the release build has completed. The standard package includes the native MCP bridge; the Node MCP host remains a separate component. See the [agent setup guide](../../AGENT_SETUP.md), [desktop guide](../../docs/desktop-guide.md) and [release process](../../docs/releasing.md).

Generative editing requires a separately configured provider and model assets. Experimental AI selection, inpainting, denoise and enlargement workflows can still require native-detail review, and source-build or CI results do not establish fresh-machine acceptance of every packaged download. Preserve your original photographs and inspect rendered results before relying on an edit.

Report reproducible issues through [GitHub Issues](https://github.com/sheldonxxxx/RapidRAW/issues), removing private image paths and credentials from logs before sharing.
